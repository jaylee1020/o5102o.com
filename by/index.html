    브라우저에서 동작한다. 카메라 입력을 MediaPipe로 분할해 사람의 형태를 분리하고, 텍스트에서 샘플링한 파티클이 그 움직임에 밀려나며 포스터를 이룬다.

  • Unseen iPadOS · Vision 실물 디자인을 카메라로 검사하며 색각 이상 시뮬레이션과 WCAG 텍스트 대비 진단을 제공하는 앱.
    Year
    2026
    Platform
    iPadOS · Swift Playgrounds
    Links
    GitHub ↗

    Swift Student Challenge 2026 출품작. 포스터, 교과서, 표지판, 화면 UI를 현장에서 바로 검사하는 도구다.

    AVFoundation으로 받은 카메라 프레임을 CoreImage 색상 행렬로 바꿔 Normal, Deuteranopia, Protanopia, Tritanopia 네 모드를 실시간으로 보여준다. Vision OCR로 텍스트를 찾아 WCAG 대비를 계산하고 PASS/FAIL 배지를 겹친다.

    탭하면 HEX/RGB 값과 모드별 변환, 대체 색상 제안을 볼 수 있고 FAIL 영역에서는 햅틱이 울린다. 프레임 고정, 카메라가 없을 때의 샘플 모드, VoiceOver 레이블과 Dynamic Type을 지원한다.

  • KU Notice Monitor Python 대학 공지를 수집해 사용자의 프로필과 관심사에 맞춰 분류·전달하는 다중 사용자 알림 시스템.
    Year
    2026
    Platform
    Python · GitHub Actions · Telegram
    Links
    GitHub ↗

    학사, 장학, 취창업 등 공지 RSS 피드를 매일 수집하고 새 공지 본문을 크롤링한 뒤, Gemini로 사용자별 관련도를 1~5점으로 매긴다. API 키가 없거나 쿼터를 넘기면 키워드 매칭으로 자동 전환한다.

    사용자는 봇에게 /profile로 학과, 학년, 캠퍼스를 등록하고 /filter로 알림 강도를 정한다. 관리자 승인 기반의 다중 사용자 구조이며 /delete_me로 자기 정보를 지울 수 있다.

    GitHub Actions 워크플로우 두 개(15분 주기 명령 처리, 매일 오전 10시 공지 모니터링)로 돌아간다. 별도 서버 없이 무료로 운영된다.
